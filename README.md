## 🌟 Sobre o Projeto

**Nexa AI** é uma plataforma moderna de desenvolvimento impulsionada por inteligência artificial, projetada para permitir que usuários criem aplicações web e interfaces completas apenas conversando com uma IA, em um conceito semelhante a ferramentas como Bolt.new, v0 e Lovable.

O projeto conta com uma interface altamente polida, design moderno em modo escuro (*dark mode*), navegação fluida por workspaces e um ambiente pronto para processamento de prompts e geração de código.

---

## ✨ Funcionalidades

- **Workspace Dinâmico**: Ambiente de trabalho interativo para gerenciamento e criação de projetos[cite: 10].
- **Interface Moderna e Estilizada**: Desenvolvida com Tailwind CSS, focando em micro-interações, gradientes personalizados, efeitos de vidro (`glassmorphism`) e temas dinâmicos[cite: 11].
- **Navegação por Rotas**: Gerenciamento de páginas estruturado com `react-router-dom` (Home, Projetos, Favoritos, Configurações e Espaços de Trabalho)[cite: 10].
- **Paleta de Comandos & Sistema de Alertas**: Atalhos rápidos e notificações integradas para uma melhor experiência de uso[cite: 10].

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando uma stack moderna de alta performance:

* **[React](https://react.dev/)** - Biblioteca JavaScript para construção de interfaces.
* **[TypeScript](https://www.typescriptlang.org/)** - Superset tipado para maior segurança no desenvolvimento.
* **[Vite](https://vitejs.dev/)** - Empacotador e ambiente de desenvolvimento ultrarrápido[cite: 4].
* **[Tailwind CSS](https://tailwindcss.com/)** - Framework CSS utilitário para estilização avançada[cite: 4, 11].
* **[Zustand](https://github.com/pmndrs/zustand)** - Gerenciamento de estado global leve e escalável[cite: 4].
* **[React Router DOM](https://reactrouter.com/)** - Roteamento dinâmico de páginas[cite: 4, 10].
* **[Lucide React](https://lucide.dev/)** - Biblioteca de ícones modernos[cite: 4].

## 📥 Como Rodar o Projeto Localmente

Siga os passos abaixo para clonar e executar a aplicação na sua máquina:

```bash
# 1. Clone o repositório
git clone [https://github.com/palomagl/nexa_ia.git](https://github.com/palomagl/nexa_ia.git)

# 2. Entre na pasta do projeto
cd nexa_ia

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
